# EZA Logistics

Modern logistics and freight management platform built with React, TanStack Router, and Tailwind CSS.

## Features

- **Dark/Light Mode** - Noir Champagne dark theme with clean light mode
- **Service Management** - Same-day courier, next-day delivery, freight, and international shipping
- **Real-time Coverage Map** - Interactive UK coverage visualization
- **Animated Hero** - Luxury particle effects and route animations
- **Responsive Design** - Mobile-first approach with smooth animations

## Tech Stack

- **React 18** - UI framework
- **TanStack Router** - Type-safe routing
- **TanStack Start** - Full-stack React framework
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Animation library
- **TypeScript** - Type safety

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is configured for Cloudflare Pages deployment via Vercel.

## Color Scheme

**Noir Champagne** - Premium luxury aesthetic
- Dark Mode: #0F1011 background with #C8A979 champagne accents
- Light Mode: #FFFFFF background with #A67C52 darker champagne
- Accent: #D94A4A luxury red for express/urgent elements
